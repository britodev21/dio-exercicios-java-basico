# Exercícios de Java · DIO

Exercícios resolvidos durante o bootcamp de Java da [DIO](https://www.dio.me/), praticando os fundamentos da linguagem e de orientação a objetos.

Cada pasta é um exercício independente, com o próprio README explicando o enunciado, como pensei a solução e como executar.

## Exercícios

| # | Exercício | Conceitos praticados |
|---|-----------|----------------------|
| 01 | [Envio de mensagens de marketing](./01-mensagens) | Interface, polimorfismo, `List`, lambda |
| 02 | [Cálculo de tributos de produtos](./02-tributos) | Classe abstrata, herança, `protected`, pacotes |

## Como executar

Pré-requisito: JDK instalado.

Abra a pasta do exercício no VS Code e rode o `App.java`. Os comandos para rodar pelo terminal estão no README de cada exercício.
